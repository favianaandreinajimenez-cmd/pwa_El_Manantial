# El Manantial - Sistema de Gestión Láctea

Sistema web para el control de producción láctea, gestión de unidades productivas y administración de personal.

## Tecnologías Utilizadas

* **Frontend:** HTML5, Tailwind CSS, Vue 3 (vía CDN)
* **Backend / API:** Node.js, Express (vía `server.js`)
* **Persistencia:** JSON Server / `db.json` y `localStorage`
